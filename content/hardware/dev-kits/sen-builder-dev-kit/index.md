## Introduction

An all-in-one dev kit for building your next custom secure node. A secure Linux computer engineered for edge applications that demand a high standard of security, flexibility, and resilience, for operation in zero trust environments.

**Includes:**

* Zymbit Secure Base Board with extensive I/O
* Raspberry Pi CM5 - 8GB RAM, 32GB Flash, no Wi-Fi
* HSM64 hardware security module
* Zymbit Power over Ethernet (PoE) module, dual input capable
* Perimeter breach detection circuits (x2)
* Power supply - 12VDC, 2.5A, 30W US adapter
* Zymbit AUXiliary breakout cable and PCB
* USB female to USB cable

## Specifications

Full specifications are available on the [Secure Node Builder Super Dev Kit](https://store.zymbit.com/products/secure-node-builder-super-dev-kit) product page.

Key specifications:

* M.2 M-Key PCIe x1 slot with a dedicated 3.3V/4A power rail
* Dual power rails: 5V at 4A+ and 3.3V at 4A+
* Power input: 12-24VDC barrel jack
* Two mini HDMI connectors
* Two USB 3.0 external ports
* Gigabit Ethernet with optional PoE
* Two MIPI camera/display connectors
* 12-pin Zymbit AUXiliary connector
* Intrusion detection system with accelerometer and temperature sensors
