{{/* Returns the version string of the current STABLE Bootware release, e.g. "1.3.2". Highest semver is NOT the answer. Bootware 2.0.0 is a beta and 1.3.2 is the stable release, so anything that sorts by version number alone points readers at beta documentation. Stability is otherwise only recorded in prose -- a title of "Bootware 2.0.0 (Beta)" and a linkTitle of "Bootware 1.3.2 (Latest STABLE)" -- which nothing can key off reliably. `weight` is display order, not stability: 2.0.0 sits at weight 20, above 1.3.2 at 30. So the stable release declares itself, with `stable: true` in the front matter of its version _index.md. When 2.0.0 leaves beta, move that flag; nothing else needs to change. If more than one section claims `stable: true` -- easy to do by copying a version directory -- the highest semver among the flagged ones wins, so the result stays deterministic. If NONE is flagged, this falls back to the highest semver overall, which restores the old, wrong behavior; that fallback exists only so the site still builds, and it is why the flag should never be removed without moving it. Callers: partials/pagefind-attrs.html. Three other files still carry their own copy of the highest-semver logic and share the same bug -- shortcodes/bootware_version_notice.html, section/bootware.html and the stale section/products/bootware.html -- and should be switched to this partial when they are next touched. */}} {{- $stable := "" -}} {{- $stableWeight := -1 -}} {{- $anyFlagged := false -}} {{- with site.GetPage "/bootware" -}} {{- /* First pass: sections that explicitly declare themselves stable. */ -}} {{- range .Sections -}} {{- if and .Params.version .Params.stable -}} {{- $anyFlagged = true -}} {{- $parts := split .Params.version "." -}} {{- $major := (index $parts 0) | int -}} {{- $minor := cond (ge (len $parts) 2) ((index $parts 1) | int) 0 -}} {{- $patch := cond (ge (len $parts) 3) ((index $parts 2) | int) 0 -}} {{- $w := add (add (mul $major 1000000) (mul $minor 1000)) $patch -}} {{- if gt $w $stableWeight -}} {{- $stableWeight = $w -}} {{- $stable = .Params.version -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Fallback only: no section declared itself stable. */ -}} {{- if not $anyFlagged -}} {{- range .Sections -}} {{- with .Params.version -}} {{- $parts := split . "." -}} {{- $major := (index $parts 0) | int -}} {{- $minor := cond (ge (len $parts) 2) ((index $parts 1) | int) 0 -}} {{- $patch := cond (ge (len $parts) 3) ((index $parts 2) | int) 0 -}} {{- $w := add (add (mul $major 1000000) (mul $minor 1000)) $patch -}} {{- if gt $w $stableWeight -}} {{- $stableWeight = $w -}} {{- $stable = . -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $stable -}}
