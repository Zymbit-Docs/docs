{{/* Returns the Pagefind indexing attributes for the
element of the current page, as a single safeHTMLAttr value. Pagefind indexes the rendered HTML in public/, so what gets indexed is controlled with data-pagefind-* attributes rather than a hand-maintained JSON template. Rules applied here: * data-pagefind-body restricts indexing to page content. Because at least one page on the site carries it, Pagefind indexes ONLY the marked regions -- the navbar, sidebar tree and footer are excluded everywhere without needing data-pagefind-ignore. * data-pagefind-ignore is emitted instead for pages under a superseded Bootware version, so the five old copies of the manual stop competing with the current one in every result set. Those pages stay published and linkable; they are just not indexed. Set pagefind_ignore: true in front matter to opt any other page out. Filters and result metadata are emitted separately, as carrier elements inside this region -- see partials/pagefind-filters.html for why they cannot share an attribute with each other or with
. The latest Bootware version is derived by semver from the version subsections themselves -- the same approach used in layouts/section/bootware.html -- so adding a new version directory does not require editing this file. Returns a value, so it must be called as {{ partial "pagefind-attrs.html" . }} in attribute position; returning a plain string there yields ZgotmplZ. */}} {{- /* Highest semver among the Bootware version sections. */ -}} {{- $latest := "" -}} {{- $latestWeight := -1 -}} {{- with site.GetPage "/bootware" -}} {{- range .Sections -}} {{- with .Params.version -}} {{- $parts := split . "." -}} {{- $major := (index $parts 0) | int -}} {{- $minor := cond (ge (len $parts) 2) ((index $parts 1) | int) 0 -}} {{- $patch := cond (ge (len $parts) 3) ((index $parts 2) | int) 0 -}} {{- /* Two-arg add only: variadic add is not available on the hugo-extended version pinned in package.json (0.91.x), only on the 0.151.1 used by CI. */ -}} {{- $w := add (add (mul $major 1000000) (mul $minor 1000)) $patch -}} {{- if gt $w $latestWeight -}} {{- $latestWeight = $w -}} {{- $latest = . -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* The Bootware version this page belongs to, if any. */ -}} {{- $pageVersion := .Params.version -}} {{- if not $pageVersion -}} {{- range .Ancestors -}} {{- if and (not $pageVersion) .Params.version -}} {{- $pageVersion = .Params.version -}} {{- end -}} {{- end -}} {{- end -}} {{- $superseded := and $pageVersion $latest (ne $pageVersion $latest) -}} {{- $attrs := "" -}} {{- /* Taxonomy list and term pages render empty: config.yaml declares categories and tags, but no page uses either, so /tags/ and /categories/ are content-free stubs. Keep them out of results explicitly rather than relying on Pagefind skipping them for having no words. */ -}} {{- $isTaxonomy := or (eq .Kind "taxonomy") (eq .Kind "term") -}} {{- /* The 404 page also renders through this baseof; it must never be a result. */ -}} {{- $isError := eq .Kind "404" -}} {{- if or $superseded .Params.pagefind_ignore $isTaxonomy $isError -}} {{- $attrs = "data-pagefind-ignore" -}} {{- else -}} {{- $attrs = "data-pagefind-body" -}} {{- end -}} {{- return ($attrs | safeHTMLAttr) -}}
