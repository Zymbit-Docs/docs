{{/* Banner at the top of each Bootware version landing page, telling the reader where the version they are looking at sits relative to the stable release. Two bugs fixed here: 1. It resolved `site.GetPage "section" "products/bootware"`. The content lives at content/bootware -- there is no content/products -- so the lookup returned nil and the entire banner was skipped, silently, on all six pages that call it. Nothing rendered on the live site. 2. It treated the highest version number as current. Bootware 2.0.0 is a BETA and 1.3.2 is stable, so once bug 1 was fixed this would have told readers of the stable release that they were out of date and sent them to a prerelease. Release identification now comes from partials/bootware-releases.html. Three states, so every version page says something useful: superseded warning -- older than stable; link to stable, and mention the beta beta warning -- prerelease, not for production; link to stable stable info -- confirms this is current, and points at the beta Uses Bootstrap 4 alert classes, matching the rest of the theme. */}} {{- $rel := partial "bootware-releases.html" . -}} {{- $stableVer := $rel.stableVersion -}} {{- $stablePage := $rel.stablePage -}} {{- $betaVer := $rel.betaVersion -}} {{- $betaPage := $rel.betaPage -}} {{- /* The version this page belongs to: its own, or the nearest ancestor's, so the banner still works if it is ever used on a child page. */ -}} {{- $cur := .Page.Params.version -}} {{- if not $cur -}} {{- range .Page.Ancestors -}} {{- if and (not $cur) .Params.version -}} {{- $cur = .Params.version -}} {{- end -}} {{- end -}} {{- end -}} {{- $betaLink := "" -}} {{- if $betaPage -}} {{- $betaLink = printf "Bootware %s" $betaPage.RelPermalink $betaVer -}} {{- end -}} {{- $stableLink := "" -}} {{- if $stablePage -}} {{- $stableLink = printf "Bootware %s" $stablePage.RelPermalink $stableVer -}} {{- end -}} {{- if and $cur $stableVer -}} {{- if eq $cur $stableVer -}} {{- /* Stable: confirm it, and surface the beta as an option rather than a nag. */ -}}
Bootware {{ $cur }} is the current stable release, recommended for production. {{- with $betaLink }} {{ $betaVer }} is available as a beta: see {{ . | safeHTML }}.{{ end }}
{{- else if and $betaVer (eq $cur $betaVer) -}} {{- /* Beta. The reader may have arrived from a search engine or an old link. */ -}}
Bootware {{ $cur }} is a beta release and is not intended for production use. {{- with $stableLink }} The current stable release is {{ . | safeHTML }}.{{ end }}
{{- else -}} {{- /* Superseded. */ -}}
You’re viewing documentation for Bootware {{ $cur }}, which has been superseded. {{- with $stableLink }} The current stable release is {{ . | safeHTML }}.{{ end }} {{- with $betaLink }} A {{ $betaVer }} beta is also available: see {{ . | safeHTML }}.{{ end }}
{{- end -}} {{- end -}}
