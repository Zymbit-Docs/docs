Zymbit Driver Package 2.x requires a 64-bit OS: Raspberry Pi OS (Debian 12 bookworm or Debian 13 trixie), or Ubuntu 24.04 or 26.04. Production HSM60 units require Driver Package 2.x and cannot be used on Ubuntu 22.04, Debian 11, or a 32-bit OS. Earlier units work with both Driver Package 2.x and [Driver Package 1.x](/reference/driver-package/legacy/).
