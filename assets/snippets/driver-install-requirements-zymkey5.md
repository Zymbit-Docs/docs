Zymbit Driver Package 2.0 requires a 64-bit OS: Raspberry Pi OS (Debian 12 bookworm or Debian 13 trixie), or Ubuntu 24.04 or 26.04. Production ZYMKEY5 units identify as `zymkey5`, which Driver Package 1.x does not recognize, so they require Driver Package 2.0 and cannot be used on Ubuntu 22.04, Debian 11, or a 32-bit OS. Pre-production units, which identify as an HSM6, also work with [Driver Package 1.x](/reference/driver-package/legacy/).
